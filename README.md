# Trabajo Integrador – Programación I

**Carrera:** Tecnicatura Universitaria en Programación – UTN

**Proyecto:** Sistema de Gestión de Inventario para una Ferretería

## Descripción del proyecto

Programa desarrollado en Python que permite administrar el inventario de una ferretería, registrar productos, consultar existencias, identificar artículos agotados y actualizar el stock mediante ventas y reposiciones.

## Archivos del proyecto

- `ferreteria_nuevo.py`: código fuente del programa.
- Informe del trabajo integrador en PDF, disponible en este repositorio.
